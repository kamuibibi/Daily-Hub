<h2>Daily Hub Pro — Personal Schedule & Memo PWA</h2>

<p>Daily Hub Pro is a fully client-side <strong>Progressive Web App</strong> for daily memo, task, and file management. No server. No account. No subscription. All data is stored privately in the user's browser.</p>

<p>It installs to the home screen on iOS, Android, and desktop — and works completely <strong>offline</strong>.</p>

<hr>

<h3>✅ Key Features</h3>
<ul>
<li><strong>Calendar</strong> — monthly view with memo/task dot indicators and ★ favorite / ● important flags</li>
<li><strong>Memo</strong> — per-day freeform notes with auto-save, custom tags, and tag-based insert</li>
<li><strong>Tasks</strong> — add, check, delete tasks per day; configurable complete action (strikethrough or auto-delete)</li>
<li><strong>Repeat Tasks</strong> — daily / weekly / monthly repeating tasks; delete individual instances or the whole series</li>
<li><strong>Reminders</strong> — per-task browser push notifications</li>
<li><strong>Attachments</strong> — attach images, videos, and files (IndexedDB); image/video preview</li>
<li><strong>Tag System</strong> — custom tags for memos; auto-convert tagged memo lines into tasks</li>
<li><strong>Full-text Search</strong> — search across memos, tasks, and attachment names</li>
<li><strong>Trash</strong> — soft-delete with restore for tasks and attachments</li>
<li><strong>Backup / Restore</strong> — export and import all data as a single JSON file</li>
<li><strong>Passcode Lock</strong> — numeric lock screen on app launch</li>
<li><strong>Dark &amp; Light Mode</strong></li>
<li><strong>Japanese / English language switcher</strong></li>
<li><strong>Statistics</strong> — memo, task, attachment counts and storage usage</li>
<li><strong>PWA</strong> — installable, fully offline via Service Worker</li>
</ul>
