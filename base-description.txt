【商品タイトル】
Daily Hub Pro｜メモ・タスク・添付ファイル管理 PWA（ソースコード）

===================================================
【商品説明】
===================================================

毎日のメモ・タスク・ファイルをまとめて管理できる
Progressive Web App（PWA）のソースコードです。

サーバー不要・アカウント不要・サブスク不要。
すべてのデータはブラウザ内に保存されます。
iOSやAndroidのホーム画面にインストールでき、
オフラインでも完全に動作します。

---

■ 主な機能

・カレンダー表示
　月間カレンダーにメモ・タスクの有無をドット表示
　お気に入り（★）・重要（●）フラグを設定可能

・メモ
　日付ごとのフリーテキストメモ（自動保存）
　カスタムタグの挿入に対応

・タスク管理
　日付ごとにタスクを追加・完了・削除
　完了動作を選択可能（取り消し線のみ / 2秒後に自動削除）

・繰り返しタスク
　毎日・毎週・毎月の繰り返し設定
　1件だけ削除することも、シリーズ全体を止めることも可能

・リマインダー
　タスクごとにブラウザ通知を設定

・ファイル添付
　画像・動画・ファイルを日付ごとに保存（IndexedDB使用）
　画像・動画はプレビュー表示

・タグ機能
　メモ用カスタムタグ
　特定タグを含むメモ行を自動でタスクに変換する機能

・全文検索
　メモ・タスク・添付ファイル名をまとめて検索

・ゴミ箱
　削除したタスク・添付ファイルを復元可能

・バックアップ / リストア
　全データをJSONファイルで書き出し・読み込み

・パスコードロック
　起動時に数字パスコードを表示

・ダーク / ライトモード切替

・日本語 / 英語 UI切替

・統計表示
　メモ・タスク・添付数、ストレージ使用量

・PWA対応
　ホーム画面にインストール可能、オフライン動作

---

■ 技術仕様

・HTML5 / CSS3 / バニラ JavaScript（ES2020）
・フレームワーク・ライブラリ・npmなし
・ビルド不要（ファイルをそのまま使用）
・データ保存：localStorage + IndexedDB
・オフライン対応：Service Worker

---

■ 動作確認ブラウザ

Chrome / Edge / Safari / Firefox / Samsung Internet

---

■ 内容物

・ソースコード一式（HTML, CSS, JS）
・Service Worker（オフライン対応）
・Web App Manifest（PWAインストール用）
・英語ドキュメント（documentation.html）

---

■ 導入方法

1. ZIPを解凍する
2. GitHub Pages / Netlify / 自社サーバーなど静的ホスティングにアップロード
3. URLをブラウザで開くだけで動作します

サーバー設定・データベース・バックエンド不要です。
