1. Overview

Daily Hub Pro is a fully client-side Progressive Web App (PWA) for daily memo, task, and file management. No server, no account, no subscription — all data is stored locally in the browser.

It works offline, can be installed to the home screen on iOS and Android, and supports Japanese and English UI.

2. Features

  • Calendar view — monthly calendar with memo/task indicators and favorite/important flags
  • Memo — per-day freeform text with auto-save and tag insertion
  • Tasks — add, complete, delete tasks per day; complete action configurable (strikethrough or auto-delete after 2 s)
  • Repeat tasks — daily / weekly / monthly repeating tasks with individual instance deletion
  • Reminders — per-task time-based browser notifications
  • Attachments — attach images, videos, and files per day via IndexedDB
  • Tag system — custom tags for memo categorization; memo-to-task auto-conversion tags
  • Search — full-text search across memos, tasks, and attachments
  • Trash — soft-delete with restore for tasks and attachments
  • Backup / Restore — export and import all data as a single JSON file
  • Passcode lock — numeric passcode screen on app launch
  • Themes — dark mode and light mode
  • Language — Japanese and English UI switching
  • PWA — installable, works fully offline via Service Worker
  • Statistics — memo, task, attachment counts and storage usage

3. Installation

Option A — Open directly in browser

  1. Unzip the downloaded package.
  2. Open index.html in any modern browser.
⚠️ Some browsers restrict Service Worker and IndexedDB when opening files via file://. For full functionality, use Option B or C.

Option B — Local server (recommended for development)

  1. Install Node.js if not already installed.
  2. In the project folder, run:
    npx serve .
  3. Open http://localhost:3000 in your browser.

Option C — Deploy to static hosting

Upload all files to any static host (GitHub Pages, Netlify, Vercel, your own server). No build step required.

  • GitHub Pages: push to a repository and enable Pages in Settings.
  • Netlify / Vercel: drag-and-drop the project folder.

4. Usage Guide

Selecting a date

Tap any day on the calendar. The memo and task panels below update to show that day's data. The selected day is highlighted.

Writing a memo

Type in the memo textarea. Changes are auto-saved. Use the tag selector dropdown to insert a tag at the cursor position.

Adding a task

  1. Type a task name in the task input field.
  2. (Optional) Set a reminder time with the ⏰ time picker.
  3. (Optional) Choose a repeat interval: Daily / Weekly / Monthly.
  4. Tap Add.

Completing a task

Check the checkbox next to a task. Depending on the Task Complete Action setting it will either show a strikethrough or be moved to Trash after 2 seconds.

Repeat tasks

When a repeat interval is chosen on a task, a template is saved and instances are automatically generated for future dates. Deleting one instance only hides that occurrence — the template continues. To stop all future occurrences, go to Settings → Repeat Tasks and delete the template.

Attachments

  1. Select a date on the calendar.
  2. Choose one or more files with the file picker.
  3. Tap Save attachment.

Images and videos display a preview. All files can be downloaded from the Attachment List page.

Search

Type a keyword in the search box on the home screen and tap 🔍. Results show matching memos, tasks, and attachment names.

Trash

Deleted tasks and attachments go to Trash. Open Trash from the home menu to restore or permanently delete items.

6. Backup & Restore

💡 Always export a backup before switching browsers or devices. Data is stored in the browser and is not synced automatically.

Export

  1. Go to Settings → Backup → Open backup.
  2. Tap Export JSON.
  3. A .json file is downloaded to your device.

Import

  1. Go to Settings → Backup → Open backup.
  2. Tap the file input and select your .json backup file.
  3. Tap Import JSON.
  4. Confirm the overwrite prompt. The app reloads with restored data.

7. Installing as a PWA

iOS (Safari)

  1. Open the app URL in Safari.
  2. Tap the Share button (box with arrow).
  3. Tap Add to Home Screen.

Android (Chrome)

  1. Open the app URL in Chrome.
  2. Tap the ⋮ menu.
  3. Tap Add to Home screen or Install app.

Desktop (Chrome / Edge)

  1. Open the app URL.
  2. Click the install icon (⊕) in the address bar.

9. FAQ

My data disappeared after clearing browser cache.

Data is stored in localStorage and IndexedDB. Clearing browser data removes it. Always use Export JSON before clearing cache or switching browsers.

Notifications are not appearing.

  1. Go to Settings → Notifications → Allow notifications.
  2. Accept the browser permission prompt.
  3. Make sure the browser (or PWA) is running in the background.

The app is showing an old version.

Go to Settings → Update → Clear cache & restart. This unregisters the Service Worker and reloads the latest files.

A repeat task keeps reappearing after I delete it.

Deleting a single occurrence only hides that date's instance. To stop all future occurrences, go to Settings → Repeat Tasks and delete the template.

Can I use this on multiple devices?

Data does not sync automatically between devices. Use Export JSON on the source device and Import JSON on the destination device to transfer data.
